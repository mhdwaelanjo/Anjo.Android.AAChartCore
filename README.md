# Anjo.Android.AAChartCore

---------------------------------
AAChartCore SDK for .NET for Android (formerly Xamarin.Android) Binding Library - Wael Anjo
---------------------------------

An elegant modern declarative data visualization chart framework for Android. Extremely powerful, supports line, spline, area, area spline, column, bar, pie, scatter, angular gauges, area range, area spline range, column range, bubble, box plot, error bars, funnel, waterfall, and polar chart types.
https://github.com/AAChartModel/AAChartCore
